### 결정 기록
- **요금은 비율로, 단가는 공식 출처만**: 웹 요금표끼리 모델 버전·단가가 엇갈려(같은 달 기준인데도 모델명이 다름) 본문에는 캐시 약 90%·배치 50%·오프피크 50% 같은 안정적 비율과 공식 문서로 확인된 Claude 단가만 쓰고, 중국 모델 개별 단가는 "몇 분의 1" 범위로만 서술. 계산 예시는 모두 비율 기반 — 단가가 바뀌어도 낡지 않게.
- **"꼼수"의 경계**: 사용자 요청(우회·꼼수도 재량으로 평가받는다)을 반영하되, 약관 안의 최적화(캐싱·오프피크·배치·라우팅·무료 티어 정상 사용·오픈웨이트 로컬 실행)는 적극 안내하고, 약관 위반(계정 공유·다계정·비공식 프록시·타인 키·레이트 리밋 우회)은 방법이 아니라 결과(계정 정지·법적 책임·보안 위반)만 서술. 이 구분 자체를 "평가받는 재량"으로 마무리.
- Claude Code 명령은 code.claude.com/docs/en/costs에 있는 것만 사용(`/cost`는 문서에 없어 제외, `/usage`·`/context`·`/compact` 등 사용).
- 검수 정정: 배치 24시간 서술(최대 소요가 아니라 미처리 시 만료), 출력 토큰이 비싼 이유(계산량이 아니라 순차 생성), 캐시 수명(API 키 기본 5분).

- 커서 이동은 CSS transition(left/top), 물결은 CSS keyframes(demo-ripple), 타이핑은 글자 단위 상태 갱신. 요소 위치는 `data-demo-id` 속성을 런타임에 조회(getBoundingClientRect → % 좌표)해 반응형에서도 정확.

### 11. 데모 액션 target 오타는 타입체크로 못 잡음
- **문제**: 액션의 target은 문자열 id라서 존재하지 않는 id를 참조해도 컴파일이 통과하고, 재생 시 해당 스텝만 조용히 건너뛰어짐. 9개 에이전트가 병렬 집필하면 오타 위험이 큼.
- **해결**: `scripts/validate-content.ts` (`npm run content:check`) 신설 — 모든 데모의 target/from/to를 앱 요소 id와 대조, id 중복·등장 경로 없는 hidden 요소·슬러그 중복까지 검사. 에이전트에게도 자가 대조를 지시.
- **교훈**: 문자열 참조로 연결되는 데이터는 반드시 전용 검증기를 함께 만든다. 타입 시스템 밖의 무결성은 스크립트로 지킨다.

### 12. prose 스타일이 코드블록 내부까지 오염
- **증상**: 마크다운 fenced 코드블록 안의 각 줄에 인라인 코드용 bg-muted 배경이 상자처럼 표시됨.
- **원인**: `prose-code:bg-muted` 등이 `<pre>` 안의 `<code>`에도 적용됨.
- **해결**: `[&_pre_code]:bg-transparent [&_pre_code]:p-0` 오버라이드 추가.
- **교훈**: prose-code 커스터마이징 시 pre>code 케이스를 항상 함께 처리할 것.

### 13. 재생 루프의 재귀 호출이 lint 에러 (react-hooks/immutability)
- **증상**: `runFrom`(useCallback)이 loop 모드 반복을 위해 자기 자신을 재귀 호출 → "Cannot access variable before it is declared".
- **해결**: 재귀 대신 `for(;;)` 무한 루프 + `start = 0; continue` 구조로 변경. useCallback 내부에서 자기 참조가 필요해지면 재귀가 아니라 루프로 풀 것.
- 함께 수정: 스크립트에서 `module` 변수명 사용 금지 (@next/next/no-assign-module-variable).

### 14. 입력창 '전송 후 비우기' 시연을 위한 hide 시맨틱 확장
- 채팅 데모에서 메시지 전송 후 입력창을 비워야 자연스러움. 별도 clear 액션 대신 `hide`가 타이핑된 텍스트도 제거하도록 확장하고, `hide → reveal` 연쇄로 "비워진 입력창 복원" 패턴을 표준화. (validate-content가 이 패턴의 reveal을 경고하지만 의도된 것 — 경고 메시지에 명시.)

### 1. 콘텐츠 템플릿 리터럴의 미이스케이프 백틱 → 파일 전체 구문 에러
- **증상**: `npx tsc --noEmit`에서 `loop-engineering.ts` 285행 부근에 다수의 파싱 에러. 병렬 집필 에이전트 9개가 전원 동일하게 보고.
- **원인**: 레슨 `content`는 TS 템플릿 리터럴(백틱 문자열)인데, 본문 안 인라인 코드의 백틱(`` `npx vitest run` ``)을 이스케이프하지 않아 문자열이 중간에 종료됨.
- **해결**: 해당 인라인 코드 제거로 즉시 수정. 이후 콘텐츠 작성 규칙으로 "본문 내 모든 백틱은 `\``로 이스케이프" 명문화.
- **교훈**: 콘텐츠를 코드로 관리할 때는 집필 가이드에 이스케이프 규칙을 반드시 포함할 것. 에이전트들이 "다른 파일 수정 금지" 지시를 지키며 에러만 보고해 준 덕에 조기 발견 — 병렬 작업 시 각자 검증(tsc) 지시가 유효했다.

### 2. 마크다운 `**"...."**한글` 볼드가 렌더링되지 않음
- **증상**: 레슨 화면에서 `**"단, 최대 N번까지..."**를` 가 볼드 처리되지 않고 `**` 리터럴이 그대로 노출.
- **원인**: CommonMark 플랭킹 규칙 — 닫는 `**`가 따옴표(문장부호) 뒤 + 한글(문자) 앞에 오면 right-flanking 조건을 못 만족해 강조로 해석되지 않음. 한국어+따옴표 조합에서 흔히 터지는 케이스로, 20여 곳에서 동일 패턴 발견.
- **해결**: 콘텐츠 20여 곳을 일일이 고치는 대신 렌더러에서 근본 해결 — `lesson-markdown.tsx`의 `fixBoldQuotes()`가 `**"X"**` → `"**X**"`로 전처리 (따옴표를 볼드 밖으로; 시각적으로 동일하고 규칙 만족).
- **교훈**: 콘텐츠 전반에 퍼진 패턴 문제는 콘텐츠 수정이 아니라 렌더러 층에서 해결한다. 이 전처리는 제거 금지.

### 3. tailwind typography가 블록쿼트에 자동 따옴표 삽입
- **증상**: `> 💡 핵심:` 콜아웃 앞뒤에 의도하지 않은 “ ” 따옴표 표시.
- **원인**: `@tailwindcss/typography`의 기본 스타일이 `blockquote p::before/after`에 open/close-quote를 넣음.
- **해결**: 래퍼에 `[&_blockquote_p:first-of-type]:before:content-none` 등 arbitrary variant로 무효화.

### 4. 재빌드 후 페이지가 스타일 없이 깨져 보임 (가짜 버그)
- **증상**: 수정 → 재빌드 → 스크린샷을 찍었더니 CSS가 전혀 없는 원시 HTML로 렌더링. 수정사항도 반영 안 된 것처럼 보임.
- **원인**: `pkill -f "next start"`가 실제 서버 프로세스를 못 죽였고, 옛 서버가 포트를 점유한 채 살아남음. 새 `next start`는 EADDRINUSE로 조용히 실패. 옛 서버의 HTML이 참조하는 CSS 청크 해시가 재빌드로 삭제되어 스타일이 통째로 404.
- **해결**: `lsof -ti :포트 | xargs kill -9`로 포트 기준 정리 후 재시작.
- **교훈**: "스타일이 전부 사라졌다"는 CSS 버그가 아니라 **stale 서버 신호**일 가능성부터 의심. 서버 재시작은 항상 포트 기준으로.

### 5. lucide-react에서 `Github` 아이콘 제거됨
- **증상**: `Module '"lucide-react"' has no exported member 'Github'` 타입 에러.
- **원인**: 최신 lucide-react가 브랜드 아이콘을 제거.
- **해결**: 로그인 폼에 인라인 SVG로 GitHub/Google 아이콘 직접 정의 (`auth-form.tsx`).

### 6. shadcn CLI 옵션 변경
- **증상**: `shadcn init -b zinc` 실패 — "Expected 'radix' | 'base' | 'aria'".
- **원인**: 최신 shadcn CLI에서 `-b`가 base color → 컴포넌트 라이브러리 선택으로 의미 변경. `-y`만으로는 테마 프롬프트가 떠서 비대화형 실행 불가.
- **해결**: `npx shadcn@latest init -d -b radix -f` (`-d`가 기본 프리셋 적용).

### 7. 홈 디렉토리의 잘못된 package-lock.json이 Turbopack 루트 추론을 오염
- **증상**: 빌드 시 "Detected additional lockfiles" 경고.
- **원인**: `~/package-lock.json`이 존재해 워크스페이스 루트 추론이 흔들림.
- **해결**: `next.config.ts`에 `turbopack.root: __dirname` 고정. (근본 해결은 홈의 lockfile 삭제지만 사용자 파일이라 건드리지 않음.)

### 8. 모바일(390px)에서 cycle 일러스트 좌우 노드 잘림
- **증상**: 사이클 다이어그램의 3시/9시 방향 노드가 화면 가장자리에서 클리핑.
- **원인**: 노드 카드 폭(w-31) 절반이 반지름 38% 위치에서 좁은 컨테이너를 초과.
- **해결**: 타원형 배치 — 가로 반지름만 33%로 축소(RX), 노드 폭 `w-26 sm:w-31` 반응형.
- **교훈**: 절대 배치 다이어그램은 최소 뷰포트(390px)에서 반드시 확인.

### 9. 잔디 그래프 월 라벨 줄바꿈 ("3월" → "3"/"월" 두 줄)
- **원인**: 라벨 셀 폭(w-3.5)이 두 글자보다 좁아 자동 줄바꿈.
- **해결**: `whitespace-nowrap overflow-visible`로 이웃 셀 위로 흘러넘치게 허용.

### 10. E2E 테스트 기대값 오류 (기능은 정상)
- **증상**: "상세 CTA 이어보기 전환" 체크 FAIL.
- **원인**: 테스트 시나리오에서 키보드 →로 이동하며 레슨이 하나 더 완료되어 "1/10"이 아닌 "2/10"이 표시됨. 기능 자체는 정상 (신규 컨텍스트로 재검증 PASS).
- **교훈**: E2E 실패 시 기능 버그와 테스트 기대값 오류를 구분해 판정할 것. 키보드 →는 '다음'과 동일하게 완료 처리된다는 명세를 테스트에 반영해야 함.

## 아키텍처 결정 기록 (ADR 요약)

- **콘텐츠 = 코드, DB = 진도**: PRD는 콘텐츠도 DB 스키마로 정의했지만, 콘텐츠를 로컬 TS 데이터로 두고 시드 SQL을 자동 생성하는 방식 채택. 이유: 타입 안전, SSG(121페이지 정적 생성), 데모 모드 완전 동작, 콘텐츠 리뷰가 코드 리뷰로 통합됨.
- **user_progress는 lesson_id 대신 lesson_key**("코스슬러그/레슨슬러그") 사용: 콘텐츠 재시드에도 진도가 안정적으로 유지되도록.
- **일러스트를 구조화 데이터로**: 103개 레슨에 개별 이미지를 만들면 품질 편차와 관리 비용이 커짐 → 8종 렌더러가 그리는 데이터 형식으로 통일.
- **강의 집필 파이프라인**: 예시 강의 1개를 직접 집필해 품질 기준 확립 → 나머지 9개는 병렬 에이전트에게 "types.ts + 예시 파일 참조, 자기 파일만 생성, tsc로 자가 검증" 지시. 재사용 가능한 패턴.
